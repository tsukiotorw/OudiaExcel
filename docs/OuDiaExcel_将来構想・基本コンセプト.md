# OuDiaExcel 将来構想・基本コンセプト

最終更新：2026年11月23日

## 1. プロダクトの基本コンセプト

OuDiaExcelの主題は、

**「OuDiaSecondのデータを使って、美しい時刻表を作ること」**

である。

単に駅時刻表をExcelに出力するツールではなく、実在する鉄道の駅時刻表を細部まで再現したり、架空鉄道のオリジナル時刻表を作ったりできる、自由度の高い時刻表デザインツールを目指す。

### 主な利用者

- A列車で行こう9などの鉄道動画投稿者
- 架空鉄道の時刻表を作りたい人
- 実在する鉄道の時刻表を再現したい人
- 時刻表のデザインやレイアウトにこだわりたい人

特に、実際の駅に掲示されている時刻表の再現性を重視する。

## 2. 時刻表の編集機能

現在は設定項目を変更することでデザインを調整する方式だが、将来的にはさらに自由度を高める。

目指す方向は次のとおり。

- 駅名欄、列車欄、凡例、注記などを個別に編集できる。
- 各構成要素の配置やサイズを自由に変更できる。
- 最終的にはマウスでドラッグして配置できる。
- 時刻表全体を自由にデザインできる。

これは最終的な目標であり、現段階で大規模な編集機能を実装するわけではない。

## 3. プリセット機能

プリセットは、時刻表のデザインを簡単に利用・共有するための重要な機能と位置付ける。

### 公式プリセット

- 運営側が制作・公開するものに限定する。
- 初期リリース時に2種類程度を用意する。
- 利用者が自由に編集できる。
- 公式プリセットを登録解除することもできる。

### ユーザープリセット

- 利用者が自分のデザインを投稿できる。
- 他の利用者が検索・取得できる。
- 改変・派生・再公開が可能。
- 元の作者へのリスペクトを大切にする。

### プリセットの管理

- プロジェクトごとに管理する。
- 複数のプリセットを保持できる。
- 自由に切り替えられる。
- 適用時はプリセットの設定を一括適用する。
- カスタマイズしても、ベースとなったプリセットとの関係を保持する。
- カスタマイズした設定を新しいプリセットとして保存できる。

### プリセットの保存・共有

プロジェクトへの同梱だけでなく、外部ファイルとして取り扱える方向を目指す。

これにより、プロジェクト内での管理とプリセット単体での共有の両方を実現する。

Windows版とWeb版の両方で同じプリセットを利用できることも重要とする。

## 4. 作品共有・コミュニティ機能

完成した時刻表を他の利用者に見てもらえる場所を設ける。

ただし、共有対象は明確に限定する。

### 完成作品の画像

- 時刻表の見た目を紹介するためのもの。
- 閲覧・参考・イメージ共有が目的。
- 実際の作品データとしてダウンロードする対象ではない。

### デザインプリセット

- 実際にダウンロードして利用する成果物。
- 自分のプロジェクトに適用できる。
- 改変・派生・再公開が可能。

プロジェクトファイルや `.oud2` データの共有は対象外とする。

### 投稿・閲覧機能

| 機能 | 方針 |
|---|---|
| タイトル | 投稿者が自由に設定 |
| 投稿者 | 作者が分かるように表示 |
| いいね | 設ける |
| 閲覧数 | 設ける |
| ダウンロード数 | プリセットに設ける |
| 編集・削除 | 投稿者自身が可能 |
| 新着順 | 設ける |
| 人気順 | 設ける |
| キーワード検索 | 設ける |

鉄道会社や路線ごとの細かなカテゴリー分類は不要とする。

## 5. プリセットの利用・派生に関する考え方

初期段階では、自由な創作活動を重視する。

- プリセットは自由に利用可能。
- 自由に改変可能。
- 自由に再配布可能。
- 派生作品の公開も可能。
- 元の作者への自動通知は不要。
- 元作品の情報は自己申告で記録する。
- 元作品をコメントなどに明記することを推奨する。

厳格な管理よりも、クリエイター同士の良識とリスペクトを大切にする方針とする。

## 6. 出力機能

出力形式の優先順位は次のとおり。

### 画像出力

重視する機能。

完成した時刻表を画像として出力し、動画や画像編集ソフトなどで利用できるようにする。

### Excel出力

補助的な機能。

Excel上でさらに加工・再利用したい利用者向けとする。

**画像出力をExcel出力より重視することを明確な方針とする。**

## 7. 時刻表プロジェクト機能

将来的には、時刻表を単なる一時的な出力物ではなく、継続して編集できる「プロジェクト」として管理する。

- プロジェクト単位で設定を保存する。
- 自動保存と手動保存に対応する。
- 名前を付けて保存・別名保存ができる。
- `.oud2` ファイルはプロジェクトに内包せず、外部参照とする。
- プロジェクトにはデザインや表示設定などを保存する。

プロジェクトの仮称は `.oudproj` とする。

### Windows版とWeb版の相互利用

これは重要な目標とする。

- Windows版で作ったプロジェクトをWeb版で開ける。
- Web版で編集したプロジェクトをWindows版で開ける。
- 共通のプロジェクト形式を利用する。
- 共通の設定仕様を維持する。

クラウド同期を必須とするわけではなく、まずはプロジェクトファイル自体の互換性を重視する。

## 8. アカウント・クラウド・プライバシー

情報漏洩リスクを抑えるため、ユーザー情報はなるべく保持しない方針とする。

- アカウント情報は必要最小限。
- 氏名・住所などは原則収集しない。
- ローカル利用を尊重する。
- 基本機能はアカウントなしでも利用できる方向とする。
- ローカル保存を基本とする。
- クラウド保存は任意とする。
- クラウド上のプロジェクトは初期状態で非公開とする。
- 作品公開は利用者の明示操作によるものとする。
- 利用者自身がクラウド上のデータを削除できるようにする。

## 9. 構想の全体像

OuDiaExcelは、美しい時刻表を作るためのデザインツールを目指す。

### 時刻表制作

自由なレイアウト・編集。

### プリセット

制作・取得・改変・共有。

### 作品共有

完成画像の公開・閲覧。

### プロジェクト

保存・再編集。

### Windows版 ⇔ Web版

共通プロジェクト・共通プリセットによる相互利用。

## 10. 今後の構想で大切にしたいこと

OuDiaExcelが目指す方向性は、次の3つに集約できる。

1. **再現性**：実在する駅時刻表を細部まで再現できる。
2. **創造性**：架空鉄道やオリジナルデザインを自由に作れる。
3. **共有性**：デザインをプリセットとして共有し、クリエイター同士で発展させられる。

そして、開発ではWindows版とWeb版の両方を育て、利用環境を問わず同じ作品を扱えることを目指す。

## 開発における基本的な考え方

この将来構想は長期的な目標であり、すべてを一度に実装するものではない。

現在の開発では、既存機能を維持しながらWindows版とWeb版の機能差をなくし、段階的にデザインの自由度を高める。

将来の機能を追加するときも、再現性・創造性・共有性という3つの方向性を意識する。

ただし、将来構想に記載されている機能が、現時点ですでに実装されていることを意味するものではない。
