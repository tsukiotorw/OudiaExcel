# 駅略称の仕様

## 1. 目的

OuDiaSecond形式の路線データにおける駅略称の設定・保存・表示に関する仕様を定義する。

## 2. 同名駅の扱い

OuDiaSecondでは、分岐駅などの構造により、同じ駅名の駅が複数存在する場合がある。

OuDiaExcelでは、**同じ駅名を持つ駅の略称は共通とし、個別には設定しない。**

### 編集画面

- 同名駅の入力欄は同じ略称の値を共有する。
- いずれかの入力欄を変更すると、同名駅の入力欄すべてに変更が反映される。
- 同名駅の略称が異なっている既存データでは、路線データ内で最初に出現する駅の略称を初期値として採用する。

### 保存・読み込み

- 同名駅には同じ略称を適用する。
- 保存形式は駅名をキーとする既存の辞書形式を維持する。
- 略称が空欄の場合は、正式駅名を使用する。

## 3. 変更時の確認事項

駅略称の編集・保存処理を変更する場合は、以下を確認する。

- 同名駅の入力欄が連動すること。
- 同名駅の略称が同じ値で保存されること。
- 設定を再読み込みした際に略称が復元されること。
- 異なる駅名の略称設定に影響しないこと。
